# Класс 2: события логов PgBouncer

[English version](pgbouncer.md)

`pgbouncer_events` содержит одну строку на событие. Формат `2_100_002` добавляет контекст соединения к `2_100_001`. Оба формата читаются. См. [код формата](../../crates/kronika-registry/src/codec/pgbouncer_events.rs) и [справочник Events](../features.ru.md#events).

## Источник и поля

Коллектор обнаруживает `logfile` через `SHOW CONFIG` с подключениями `--pgbouncer-dsn` или `KRONIKA_PGBOUNCER_DSNS`. `--pgbouncer-log` или `KRONIKA_PGBOUNCER_LOGS` добавляет локальные пути и шаблоны. `SHOW POOLS`, `SHOW STATS` и `SHOW CLIENTS` не собираются.

| Поле | Допускает null | Определение |
| --- | --- | --- |
| `ts` | нет | Микросекунды Unix. Время источника учитывает UTC, числовое смещение и зоны IANA, иначе используется локальная зона коллектора. При отсутствующем или неверном времени используется время чтения пакета. |
| `source_file` | нет | Прочитанный файл. |
| `level` | нет | `0` FATAL, `1` ERROR, `2` WARNING, `3` LOG, `4` DEBUG, `5` NOISE. |
| `database` | да | Секция базы в `pgbouncer.ini`. |
| `username` | да | Пользователь или имя peer. |
| `host` | да | Адрес клиента/сервера без однозначного суффикса порта. Скобки IPv6 и `unix(<pid>)` сохраняются. |
| `pid` | да | PID процесса PgBouncer. |
| `side` | да | `C` — клиент, `S` — сервер. |
| `port` | да | Порт соединения. Ноль сохраняется. |
| `age_s` | да | Возраст соединения в целых секундах, если указан. |
| `text` | нет | Полное сообщение с продолжениями, начинающимися с табуляции, до 5 КиБ. |

PID, сторона, порт и возраст отсутствуют в прежнем формате. Недостающий контекст остаётся null. `(nodb)`, `(nouser)` и имена peer сохраняются буквально.

## Отбор сообщений

Все распознанные WARNING, ERROR и FATAL сохраняются, включая `pooler error:`. Неизвестные LOG, сигналы, перезагрузки конфигурации и неожиданные отключения сохраняются. DEBUG и NOISE пропускаются.

Штатные LOG о соединениях и числовая периодическая статистика пропускаются. Нормальные причины закрытия: `client close request`, `server idle timeout` и `server lifetime over`. Неизвестные причины и некорректный суффикс возраста остаются видимыми.

```text
2026-09-21 12:34:56.789 [12345] WARNING C-0x55f1: db/user@10.0.0.1:41537 closing because: query timeout (age=42s)
```

Записываются PID `12345`, сторона `C`, порт `41537`, возраст `42` и полное сообщение `closing because: query timeout (age=42s)`. Events убирает обёртку закрытия и корректный возраст только из ключа группировки. Детали представителя сохраняют записанное сообщение.
