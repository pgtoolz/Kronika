# Интерфейс и справочник данных

[English version](features.md) · [Руководство оператора](operator-guide.ru.md) · [README](../README.ru.md)

Kronika записывает снимки состояния Linux, статистику PostgreSQL и события из журналов. Веб-интерфейс и выгруженный HTML рассчитывают показатели по этим записям одним и тем же кодом. Снимок — набор значений, полученных при одном опросе источника; время опроса сохраняется вместе с ними.

| Справочник | Содержание |
| --- | --- |
| [Время, агрегация и Health](metrics-time.ru.md) | Выбор часа и момента, интервалы между снимками, разности счётчиков, тепловые карты, статистика графиков и показатель состояния Health. |
| [Linux](metrics-linux.ru.md) | Процессы, ресурсы машины и контрольных групп контейнера, CPU, память, диски, файловые системы, сеть и сводка USE. |
| [PostgreSQL](metrics-postgresql.ru.md) | Сводка сервера, базы данных, сеансы, блокировки, очистка таблиц, запросы, планы, таблицы, индексы и настройки. |
| [Events](#events) | Группировка событий журналов, расчёт количеств и выбор полной записи. |
| [MCP](#mcp) | Четырнадцать инструментов для программного чтения записей: параметры, ограничения и поля ответа. |
| [Export](#export) | Выбор времени и выгрузка автономного HTML. |
| [Установка](../INSTALL.ru.md) | Готовые программы, сбор данных, доступ к веб-интерфейсу и сборка из исходников. |

## Элементы управления

Курсор задаёт выбранный момент времени. Раздел выбирает вид объектов, например Processes — процессы или Events — события. Режим таблицы, называемый в интерфейсе **Lens**, выбирает набор столбцов и начальную сортировку. **Inspector** — панель сведений о выбранной строке: вкладка **Detail** показывает её поля, **Chart** — историю показателя. Названия кнопок ниже сохранены в том виде, в котором они встречаются в интерфейсе.

| Элемент | Состояние или действие |
| --- | --- |
| День/час; предыдущий/следующий час | Выбор календарного часа. Графики сохраняют диапазон полного часа. |
| Browser time / UTC | Местное время браузера или UTC для подписей и календаря. Записанные метки времени в микросекундах Unix не меняются. |
| Часы рабочей области; указатель временной шкалы | Предварительный просмотр записанного момента под указателем. Отпускание фиксирует курсор; уход со шкалы возвращает ранее выбранный момент. |
| ← / →; предыдущее/следующее наблюдение | Переход к соседней из загруженных меток времени текущего раздела. Метки разных источников объединяются, сортируются и очищаются от повторов. Кнопки, поля ввода и списки сохраняют собственные действия стрелок. |
| Refresh | Повторная загрузка перечня записей и текущего раздела. Видимый текущий час обновляется через 15 секунд после окончания загрузки, а при возвращении к вкладке — сразу. Прошлые часы автоматически не обновляются. Закреплённый курсор остаётся на месте; в режиме слежения он движется к последнему наблюдению. Выбранный час не меняется. |
| View | Раздел Processes, Host, PostgreSQL или Events. |
| Lens | Набор столбцов и начальная сортировка таблицы. Формулы показателей определены в соответствующем справочнике. |
| Заголовок столбца | Сортировка всех подходящих строк до разбивки на страницы. Деревья процессов и цепочки блокировок сохраняют свою иерархию. |
| Search; Apply / Enter | Применение поискового выражения. Ошибка в новом тексте оставляет прежние результат и URL. Отдельные условия можно удалить кнопками возле строки поиска. |
| Load more / Retry | Загрузка следующей страницы или повтор неудачного запроса. Пока запрос выполняется либо завершён с ошибкой, прежние строки остаются с соответствующим статусом. |
| Строка; Inspector Detail / Chart | Выбор объекта, просмотр его записанных полей или истории показателя. Дополнительные вкладки зависят от типа объекта. |
| Метрика Chart; ряд / All | Выбор показателя и отображаемых рядов. Легенда сопоставляет цвет с рядом; наведение показывает значения, не меняя выбор. |
| Expand / restore chart | Разворачивание графика Inspector и возврат к прежнему размеру. |
| Разделитель Inspector | Изменение ширины мышью или стрелками; Home/End задают минимальную/максимальную ширину. На узком экране панель появляется поверх содержимого сбоку или снизу. |
| Заголовок Activity | Открытие таблицы вкладов за весь час, упорядоченной по выбранному показателю. Компактный вид оставляет восемь строк, остальные вклады объединяет в Other. На полном экране доступны Top 10/25/50/100; начальное значение — 25. |
| Global / Per row | Цвет тепловой карты относительно общего максимума или максимума своей строки. У Total всегда отдельная шкала. |
| Ячейка тепловой карты | Переход к `cell.to − 1 µs`: последней микросекунде интервала ячейки. Таблица выбирает снимки относительно этого момента. |
| Имя объекта в Activity | Фильтр по объекту или группе, если раздел его поддерживает. Если у курсора нет значения этой строки, курсор переходит к её наиболее нагруженному интервалу. Имена контрольных групп cgroup таблицу не фильтруют. |
| `?`; справка поля; Esc | Общая справка, определение показателя; закрытие панели или снятие выбора. |
| Copy exact value | Копирование неокруглённого значения. Если копирование недоступно, точный текст выделяется. |
| Язык; тема | EN/RU и светлая/тёмная тема. Браузер запоминает их, ширину Inspector и состояние панели Activity. |
| Sign out | Завершение сеанса на веб-сервере. |

URL сохраняет час, курсор, раздел, режим таблицы, сортировку, поиск и доступный для данного раздела выбор строки. Назад/Вперёд в браузере восстанавливает это состояние. Обычный переход к другому виду объектов очищает поисковый параметр `find`. Переход к связанному объекту задаёт новый фильтр и сохраняет время.

Исходники: [адрес и переходы](../bins/kronika-web/ui/src/address.ts), [клавиатура](../bins/kronika-web/ui/src/keyboard.ts), [обновление](../bins/kronika-web/ui/src/refresh.ts), [Activity](../bins/kronika-web/ui/src/activity.tsx), [Inspector](../bins/kronika-web/ui/src/inspector.tsx).

## Search

Поиск ограничивает строки текущей таблицы. Поле указывается его публичным именем, например `rss` или `query_id`; список имён и единиц доступен в справке поиска.

| Синтаксис | Значение |
| --- | --- |
| Обычный текст | Текстовый поиск в текущем разделе. |
| `field:value` | Условие по текстовому полю или идентификатору. Кавычки сохраняют пробелы; `*` и `?` задают шаблон строки. |
| `field>quantity`, `field<quantity` | Строго больше или меньше величины в допустимых для поля единицах. Отсутствующее значение `null` не проходит сравнение. |
| `AND`, `OR`, скобки | Логические «и», «или» и группировка. Регистр операторов неважен; `AND` выполняется раньше `OR`. Пределы: 8 условий, 31 элемент синтаксиса, 4 уровня скобок, 1024 символа. |
| `MB`, `MiB`, `/s` | Десятичные мегабайты, двоичные мебибайты, величины в секунду. Регистр единиц значим. |
| Группировка Tables/Indexes | Имена отбирают исходные объекты до суммирования, числовые условия проверяют полученные группы. `AND` может соединять эти стадии; `OR`, смешивающий их, отклоняется. |

`NOT`, неявные логические операторы, `=`, `==`, `!=`, `>=` и `<=` не принимаются. Поле поиска доступно независимо от того, показано ли оно в текущем режиме таблицы. Фильтрация выполняется до сортировки и разбивки на страницы.

```text
command:postgres* AND rss>100MiB
state:active AND wait_type:Lock
query_id:-665077864269413128
schema:shop AND table_name:orders
```

Исходники: [разбор выражений](../bins/kronika-web/ui/src/search.ts), [общие определения поиска](../crates/kronika-query/src/snapshot/search.rs).

## Настроенные и записанные источники

| Настройка или запись | Значение |
| --- | --- |
| `KRONIKA_PG_DSNS` сборщика | Параметры подключений, включающие сбор PostgreSQL. |
| Записанный `instance_metadata` | Окружение, интервалы сбора, признак включённого PostgreSQL и необязательное явное число доступных ему CPU. Эти данные задают область и время расчётов, включая Health. |
| Обязательная настройка web `KRONIKA_WEB_SOURCES` | Число с двумя признаками: `0` ни один источник не настроен, `1` ОС, `2` PostgreSQL, `3` оба. Это сведения каталога; сбор, состав записей и вкладок, а также расчёт Health от них не зависят. |
| Признак настроенного PostgreSQL в интерфейсе | Подсказка об отсутствии PostgreSQL скрыта, если источник настроен или в записи есть его данные. Признак настроенной ОС интерфейс не использует. |
| Записанный формат секции | Определяет доступные поля конкретной версии PostgreSQL или варианта расширения. Секция объединяет строки одного записанного типа. |

Исходники: [настройки web](../bins/kronika-web/src/config.rs), [наличие источников](../bins/kronika-web/ui/src/source-availability.ts), [настройки сборщика](../bins/kronika-collector/src/config.rs).

## Events

Раздел Events объединяет похожие записи журнала и показывает, когда они возникали. Диапазон запроса — не более часа. Для группы `firstTs=min(t)` и `lastTs=max(t)`, где `t` — время входящей в неё записи. В 60 минутных ячейках суммируется число событий, приходящихся на минуту. Номер ячейки равен `bucket=floor((t−from)/60,000,000)`, где `from` — начало диапазона, обе метки заданы в микросекундах Unix. Итоговое количество группы может вычисляться иначе, как указано ниже. Длительности хранятся в миллисекундах; интерфейс выбирает удобные единицы отображения.

| Группа / секция записи | Ключ группы | Количество, показатели и запись для подробного просмотра |
| --- | --- | --- |
| Errors / `pg_log_errors` | `(severity, category, pattern)` | `Σ count`; отсутствующий `count` добавляет 1. Уровень ошибки, SQLSTATE и категория берутся из самой ранней записи. База и пользователь показаны, только если у всех записей совпадает непустое значение. |
| Slow queries / `pg_log_slow_queries` | `pattern` | `Σ count`; суммарная длительность `totalMs=Σ total_duration_ms`, максимум `maxMs=max(max_duration_ms)`. В этих расчётах отсутствующие числовые длительности дают 0. Для подробного просмотра выбирается самая долгая запись, при равенстве — самая ранняя. Порог — последнее записанное неотрицательное `log_min_duration_statement`, с переводом секунд/минут в миллисекунды. |
| Autovacuum / `pg_log_autovacuum` | `(kind, relation)` | Число запусков равно числу строк. Суммируются доступные `elapsed_ms` и `tuples_removed`; число мёртвых строк, которые нельзя удалить, берётся из последней записи. `kind=1` означает analyze. Для просмотра выбирается самая ранняя запись. |
| Checkpoints / `pg_log_checkpoints` | Общая группа начал и завершений | `starts=count(phase=0)`, `completes=count(phase=1)`; показанное число — `max(starts,completes)`. Плановые начала содержат `time` в причине; число запусков по запросу равно остатку. Из завершений берутся максимум `sync_ms` и сумма `buffers_written`. Для просмотра — первая прочитанная запись. |
| Checkpoint warnings | `phase=2` | Число предупреждений и минимум доступного `seconds_apart` в секундах. Для просмотра — первая прочитанная запись. |
| Lock waits / `pg_log_lock_waits` | Точный текст `holding_pids` | Записи ожидания `kind=0` создают группы. Запись получения блокировки присоединяется к последнему предшествующему ожиданию с теми же `(pid,lock_target)`. Количество равно числу записей ожидания, минимум 1; ожидающие — различные записанные PID; длительность — максимум доступного `duration_ms`; цели — различные тексты объектов блокировки. Записи получения без соответствующего ожидания образуют отдельную группу с количеством появлений. |
| Lifecycle / `pg_log_lifecycle` | Отдельная группа каждой строки | Вид события, PID, сигнал и режим остановки из этой строки. Количество 1. |
| PgBouncer / `pgbouncer_events` | `(level, exact text)` | Число строк; для просмотра — самая ранняя запись. База, пользователь, адрес клиента и исходный файл показаны, только если у всех записей совпадает непустое значение. |

Необязательные суммы и максимумы равны `null`, если значений нет ни в одной записи. Исключение для длительностей Slow queries указано в таблице. При равных метках времени выбирается первая прочитанная запись. Группы упорядочены по уровню ниже, затем по убыванию количества, по убыванию последнего времени и по ключу группы.

| Уровень группы | Состав |
| --- | --- |
| Critical | PostgreSQL FATAL/PANIC (`severity=1/2`); событие жизненного цикла `kind=0`; PgBouncer `level=0`. |
| Notable | Остальные ошибки PostgreSQL, кроме WARNING/LOG; медленные запросы; предупреждения контрольных точек; ожидания блокировок; остальные события жизненного цикла; PgBouncer `level=1/2`. |
| Routine | PostgreSQL WARNING/LOG (`severity=3/4`); autovacuum/analyze; контрольные точки; остальные уровни PgBouncer. |

`(nodb)` и `(nouser)` — записанные значения PgBouncer, означающие, что база или пользователь соединения не заданы. Сборщик сохраняет этот текст; отсутствующее поле равно `null`. Адрес клиента хранится без порта. Группы PgBouncer показаны в Events, но не отмечаются на общей временной шкале.

Сводка по источникам и типам отбирает группы. Search ищет по показанным названиям и подписям через поля `text`, `kind`, `source`, `category`. Раскрытие группы показывает её показатели; выбор записи загружает полную строку журнала. Группа отметок на временной шкале выбирает свой интервал и источники; **Show all** возвращает весь час. Превышения порогов и резкие изменения представлены отдельным списком. Секция `pg_log_temp_files` доступна через MCP в виде `occurrences`, вне сгруппированного списка.

Исходники: [запрос событий и поля](../crates/kronika-query/src/events.rs), [расчёт групп](../crates/kronika-query/src/events/group.rs), [элементы управления Events](../bins/kronika-web/ui/src/events-view.tsx), [разбор PgBouncer](../crates/kronika-source-log/src/pgbouncer.rs).

## MCP

MCP позволяет программе-клиенту читать записи Kronika. Адрес `POST /mcp` предоставляет четырнадцать инструментов по протоколу Streamable HTTP без серверного состояния сеанса. Каждый возвращает структурированный JSON. HTTP Basic использует имя и пароль web; в режиме `KRONIKA_WEB_AUTH=disabled` проверка отключена, но обе настройки всё равно обязательны. Запросы с заголовком `Origin` или параметрами в URL отклоняются. Инструменты читают сохранённые файлы и не выполняют административных команд на машине или в PostgreSQL.

| Инструмент | Параметры | Ответ |
| --- | --- | --- |
| `kronika_list_recorded_sections` | Необязательный `section` | Начало `recorded_from` и исключительная граница `recorded_to`; секции с семейством источника, числом строк и байтов, полями, классами и единицами. |
| `kronika_get_instance` | `settings`: `non_default` (по умолчанию) или `all` | Последние сведения о машине и настройки PostgreSQL с отдельными метками `host_as_of`/`settings_as_of`, числом строк и областью. `non_default` исключает только записи с точным `source="default"`. |
| `kronika_rank_metrics` | `from`, `to`, непустой `rankings:[{section,fields,top?}]`; 1–4 поля; `top` 1–500, по умолчанию 25 | Отдельный упорядоченный результат каждого поля, включая повторы: разности счётчиков или максимумы значений, единица, идентификаторы, подписи, ссылки на полные строки, Total/Other и число объектов. У каждого поля свой предел `top`. |
| `kronika_find_processes` | Общие параметры поиска ниже | Строки процессов. |
| `kronika_find_postgresql_activity` | Общие параметры поиска | Состояния сеансов, ожидания и метки начала. |
| `kronika_find_postgresql_locks` | Общие параметры поиска | Блокировки и сведения о блокирующих процессах. |
| `kronika_find_postgresql_vacuum` | Общие параметры поиска | Ход очистки таблиц. |
| `kronika_find_postgresql_databases` | Общие параметры поиска | Статистика баз данных. |
| `kronika_find_postgresql_statements` | Общие параметры поиска | Интервальные показатели и идентификаторы запросов. |
| `kronika_find_postgresql_plans` | Общие параметры поиска | Интервальные показатели и идентификаторы планов. |
| `kronika_find_postgresql_tables` | Общие параметры поиска; обязательный `group`: `object`, `schema`, `database`, `tablespace` | Таблицы по отдельности или объединённые по схеме, базе либо табличному пространству. |
| `kronika_find_postgresql_indexes` | Общие параметры поиска; обязательный `group` с теми же значениями | Индексы с выбранной группировкой. |
| `kronika_find_events` | `from`, `to`, `limit`; `representation=groups` (по умолчанию) или `occurrences`; необязательный `sources` | Группы или отдельные события и признак усечения `truncated`; диапазон до часа. Отсутствующий или `null` `sources` выбирает поддерживаемые источники; `[]` — ни одного. Временные файлы доступны только как `occurrences`. |
| `kronika_get_row_detail` | Обязательный неизменённый `detail_ref` | Полная записанная строка. Текстовые поля содержат `stored_text`, десятичный `full_len`, `truncated`, `sha256`. |

Общие параметры поиска: необязательный `at` — выбранное время, по умолчанию последняя метка всего хранилища; необязательные `filters` и `sort:{field,direction}`; обязательный `limit` от 1 до 5000. Сортировка `asc` идёт по возрастанию, `desc` — по убыванию; `null` в конце. Без `sort` сохраняется порядок идентификаторов. Ответ `{rows,truncated}` не содержит курсора продолжения. `detail_ref` ссылается на записанный объект; у группы без единственной исходной строки такой ссылки нет.

Фильтр содержит `field`, `op`, `value`, а для операции `in` — `values`. До восьми фильтров соединяются через AND. `in` принимает 1–8 альтернатив через OR. Для текста допустимы нечувствительные к регистру `eq`, буквальный поиск подстроки `contains` и `in`. Идентификаторы принимают `eq`/`in` с целым числом или точной десятичной строкой. Числовые величины принимают строгие `gt`/`lt` с неотрицательными целыми JSON в базовой единице поля. Запрос `tools/list` возвращает имена полей и единицы для каждого вида объектов.

Время задаётся целыми микросекундами Unix, канонической знаковой десятичной строкой, RFC 3339 с часовым поясом, `now` или `now-Nus/ms/s/m/h/d/w`. `now` — время запроса. Для диапазонов используется `[from,to)`; поиск на момент выбирает наблюдения не позже `at` с учётом интервала сбора секции. Закодированные аргументы поиска, Events и ранжирования ограничены 65 536 байтами. Ошибка содержит `isError`, `record="error"`, `message` и, когда применимо, `valid_options` или `ranking_index`.

Панель **Connect an AI agent** показывает адрес `<origin>/mcp`, состояние учётных данных, выбор клиента Claude Code/Codex CLI/Cursor и готовые настройки с кнопкой Copy. Здесь `origin` — адрес веб-сервера вместе со схемой и портом. Заголовок авторизации получается через `/api/mcp-access`; если он недоступен, панель содержит шаблон без данных авторизации. [Команды и конфигурация клиентов](mcp-clients.ru.md).

Исходники: [схемы инструментов](../bins/kronika-web/src/mcp/catalog.rs), [фильтры](../bins/kronika-web/src/mcp/filter.rs), [время](../bins/kronika-web/src/mcp/time.rs), [форматы ответов](../bins/kronika-web/src/mcp/semantics.rs), [панель подключения](../bins/kronika-web/ui/src/mcp-connect.tsx).

## Export

Export создаёт один HTML-файл с записью выбранного интервала. Начало и конец задаются целыми секундами; последняя выбранная секунда входит в результат.

| Параметр или кнопка | Определение |
| --- | --- |
| From / To | Включительные секунды Unix `F,T`, `0<F≤T`; длительность `T−F+1` секунд. Каждая граница имеет свою дату; редактор использует местное время браузера либо UTC. |
| This hour | `F=floor(hour_us/10⁶)`, `T=F+3599`, где `hour_us` — начало выбранного часа в микросекундах Unix. |
| Around cursor ±5/15/30 min | При `C=floor(cursor_us/10⁶)` и `N` минутах: `F=C−60N`, `T=C+60N−1`; длительность `120N` секунд. `cursor_us` — выбранный момент в микросекундах Unix. |
| Предыдущий/следующий час | Прибавить −3600/+3600 секунд к обеим границам. |
| День и `HH:MM:SS` | Дата и время в выбранном часовом поясе. Время, пропущенное при переводе часов, отклоняется; при повторе нужно выбрать первое или второе вхождение. |
| Имя файла | `kronika-YYYY-MM-DD-HHMMSS-YYYY-MM-DD-HHMMSS-utc.html`, обе границы записаны в UTC. |
| Download | `GET /api/export?from=F&to=T`; видимый диапазон `[10⁶F,10⁶(T+1))`. Включены все записанные секции диапазона. |
| Ход выгрузки | Время подготовки в секундах, затем число принятых байтов и полный размер, если он известен. После завершения — имя файла, размер и затраченное время. Браузер сохраняет длительность предыдущей подготовки. |

HTML содержит запись, интерфейс, шрифты и модуль WebAssembly для расчёта показателей. Файл открывается локально; запросы выполняются синхронно на основном потоке браузера. Видимый диапазон фиксирован. Обновление живых данных, вход, повторный экспорт и подключение MCP в файле отключены. Записанные SQL, планы, журналы и командные строки входят в него.

Устанавливаются четыре программы: `kronika-collector`, `kronika-web`, `kronika-dump`, `kronika-report`. Команда [slice](../bins/kronika-dump/README.ru.md) извлекает интервал в ZMS; [report](../bins/kronika-report/README.ru.md) преобразует его в HTML. Их `--help` содержит параметры запуска.

Исходники: [арифметика диапазона](../bins/kronika-web/ui/src/export-range.ts), [календарное время](../bins/kronika-web/ui/src/export-time.ts), [диалог выгрузки](../bins/kronika-web/ui/src/export-dialog.tsx), [запросы автономного отчёта](../bins/kronika-web/ui/src/report-transport.ts).
