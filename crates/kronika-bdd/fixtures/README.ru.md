# Фикстуры BDD

[English version](README.md)

Каждый каталог — корень procfs, который сценарий выбирает через
`KRONIKA_PROC_ROOT`. Фикстура содержит файлы, которые читает сценарий.

`procfs-without-meminfo` содержит минимум, необходимый сборщику для запуска и
записи сегмента. Файлы `meminfo` и `vmstat` в нём отсутствуют.
