# Фикстуры BDD

[English version](README.md)

Каждый каталог содержит обычные файлы, расположенные как в procfs — файловой
системе Linux `/proc`. Сценарий BDD задаёт этот каталог в `KRONIKA_PROC_ROOT`,
чтобы сборщик читал тестовые файлы вместо `/proc` основной системы.

`procfs-without-meminfo` содержит минимум, необходимый сборщику для запуска и
записи сегмента. Файлы `meminfo` и `vmstat` в нём отсутствуют.
