# Библиотеки

[English version](README.md)

Библиотеки workspace отвечают за чтение источников, хранение и обработку
записанных данных. Приложения в [`bins`](../bins) определяют, когда выполнять
эти операции и как выдавать результат. Библиотеки не зависят от пакетов приложений.

| Библиотеки | Назначение |
| --- | --- |
| `kronika-source-os`, `kronika-source-pg`, `kronika-source-log` | Чтение источников, разбор данных и преобразование поддерживаемых строк. Сборщик PostgreSQL также обнаруживает базы и расширения, хранит состояние соединений. |
| `kronika-format`, `kronika-registry`, `kronika-derive` | Формат записи, схемы секций и кодеки. |
| `kronika-layout`, `kronika-store`, `kronika-reader`, `kronika-writer` | Доступ к хранилищу, чтение зафиксированных данных, словари строк, запись WAL и завершённых сегментов. |
| `kronika-index`, `kronika-query`, `kronika-api` | Производные индексы, выполнение запросов и разбор обращений к записанным данным. HTTP и встроенные отчёты используют общую классификацию ошибок API. |
| [`kronika-slice`](kronika-slice) | Извлечение выбранного интервала в самостоятельный ZMS. Используется в dump и веб-экспорте. |
| [`kronika-report`](kronika-report), `kronika-report-wasm` | Движок запросов отчёта, генерация HTML и адаптер для браузера. Используются в report CLI и веб-экспорте. |
| `kronika-bdd` | Сквозные сценарии проверки исполняемых программ. |

## Сбор и запись

Collector управляет расписанием, сигналами, ротацией, состоянием сегмента и
приёмом данных в WAL. Библиотекам сбора он передаёт параметры конкретного
источника. Сборщик PostgreSQL выдаёт ограниченные пакеты строк через callback
и ждёт подтверждения приёма перед чтением следующего пакета. Преобразование
OS-строк принимает callback для словаря строк; сам словарь сегмента и буфер
принадлежат collector. Библиотеки источников не зависят от writer или
конфигурации collector.

## Запросы на сервере и в отчёте

Web отвечает за HTTP-аутентификацию, заголовки, передачу ответа и транспорт MCP.
Выполнение запросов общее с отчётом в браузере. Переносимая сборка отключает
нативные возможности зависимостей query/report; генерация HTML включается
возможностью `generator` библиотеки report. Извлечение среза требует доступа
к локальному хранилищу и не входит в зависимости WASM.

Cargo-пакет исполняемой программы называется `kronika-report-cli`; имя
бинарника остаётся `kronika-report`. Пакет `kronika-report` содержит библиотеку.

[`check-query-boundary.sh`](../scripts/check-query-boundary.sh) проверяет
зависимости переносимой сборки и запрещает библиотекам зависеть от пакетов
приложений. Модульные тесты находятся в `src/tests` своего crate,
интеграционные — в `tests`.
