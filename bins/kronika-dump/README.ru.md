# kronika-dump

[English version](README.md) · [Установка](../../INSTALL.ru.md)

`kronika-dump` показывает содержимое записи: время, виды данных и отдельные
строки. Команда `slice` вырезает выбранный интервал в один файл `.zms`,
который можно передать в `kronika-report` для создания HTML-отчёта.
Исходники: [разбор команд](src/main.rs), [команда slice](src/slice.rs),
[справка параметров](src/help.rs).

<a id="inspect"></a>
## Просмотр записи

```sh
kronika-dump /var/lib/kronika
kronika-dump /var/lib/kronika --json
kronika-dump /var/lib/kronika --index
kronika-dump /var/lib/kronika --section 1100001 --limit 10
```

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| `DIR` | Обязателен | Обычный каталог записи сборщика с файлами `YYYY/MM/DD/*.zms` и, при наличии, журналом `active.wal`. Символические ссылки и пути отдельных ZMS-файлов не подходят. |
| Вывод без параметров | Сводка сегментов | Границы времени, числовые идентификаторы разделов данных, число строк, размер разделов и служебных данных файла в байтах. |
| `--section ID` | Не задан | Показать строки раздела с числовым идентификатором формата `type_id`; ссылки на словарь заменяются их значениями. |
| `--index` | Не задан | Показать сводку временных рядов и индекса; с `--json` — отдельные точки и ссылки на строки с отметками. Нельзя сочетать с `--section`; отдельный файл индекса не создаётся. |
| `--json` | Текст | Выводить по одному объекту JSON в строке (NDJSON). Предупреждения при чтении также выводятся объектами JSON в stdout. |
| `--limit N` | `20` | Неотрицательное число строк на сегмент; `0` означает все строки. Требуется `--section`. |
| `--from`, `--to` | Без границ | Целые Unix-микросекунды со знаком, обе границы включены. Выбираются сегменты, пересекающие этот интервал; строки внутри выбранных сегментов не обрезаются. Можно задать только одну границу. |

Просмотр читает готовые сегменты и сохранённую часть текущего журнала. Нужен
доступ на чтение; переменные окружения для настройки не используются. Данные
выводятся в стандартный поток вывода (stdout), текстовые предупреждения и
ошибки — в поток ошибок (stderr). Если принимающая программа закрыла канал
вывода, команда завершается успешно; остальные ошибки дают ненулевой код.

<a id="slice"></a>
## Вырезать интервал

```sh
KRONIKA_STORAGE_DIR=/var/lib/kronika kronika-dump slice \
  --from 2026-09-05T19:00:00Z \
  --to 2026-09-05T19:59:59Z \
  --out incident.zms
```

| Параметр | Значение |
| --- | --- |
| `KRONIKA_STORAGE_DIR` | Обязательный обычный каталог записи сборщика с доступом на чтение. Читаются готовые сегменты и сохранённая часть журнала. |
| `--from RFC3339` | Обязательная первая целая секунда включительно; укажите `Z` для UTC или смещение часового пояса. |
| `--to RFC3339` | Обязательная последняя целая секунда включительно, не раньше `--from`. Равные границы выбирают одну полную секунду. Дробные секунды и числовые Unix-метки времени не принимаются. |
| `--out FILE.zms` | Обязательный путь нового файла `.zms`. Родительский каталог должен существовать и быть доступен на запись. Существующий файл не перезаписывается. |

Каждый параметр задаётся один раз, в любом порядке. Выбранный интервал —
`[from, to + 1 second)`: он включает всю последнюю секунду. Результат может
содержать соседние отсчёты в пределах 30 секунд с каждой стороны для расчёта
изменений между отсчётами. Интервал без записанных строк приводит к ошибке.

Рабочие и временные файлы создаются рядом с результатом в той же файловой
системе. Готовый ZMS проверяется перед сохранением. В stdout выводятся число
байтов, строк и разделов, запрошенные и фактические границы в Unix-микросекундах.
`requested_to_exclusive` на одну секунду больше `--to`. Ошибки выводятся в
stderr и дают ненулевой код завершения.
[kronika-report](../kronika-report/README.ru.md) преобразует результат в HTML.

## Общие параметры

`-h` и `--help` открывают общую справку; `slice -h` и `slice --help` — справку
по вырезанию интервала. `--version` выводит версию программы. Эти вызовы
завершаются до обращения к хранилищу. `Ctrl+C` прерывает выполняемую команду.
