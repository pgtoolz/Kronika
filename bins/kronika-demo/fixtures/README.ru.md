# Запись демо для GitHub Pages

[English version](README.md)

`github-pages-hour-20260921T085946Z.zms` — текущая запись для Pages,
сделанная 21 сентября 2026 года за полный час демонстрационной нагрузки.
Она содержит реальные измерения Linux, PostgreSQL и PgBouncer: семь cgroup,
процессы, параллельные транзакции, ожидания блокировок, планы запросов и
429 событий PgBouncer с полными сообщениями и контекстом соединения.

`kronika-dump slice` создал отдельный файл из каталога сборщика `CAPTURE`:

```sh
KRONIKA_STORAGE_DIR=CAPTURE kronika-dump slice \
  --from 2026-09-21T08:59:46Z \
  --to 2026-09-21T09:59:45Z \
  --out github-pages-hour-20260921T085946Z.zms
```

Обе граничные секунды включены. Видимый интервал `[08:59:46, 09:59:46)` UTC
длится ровно 3 600 секунд. ZMS размером 813 685 байт содержит 57 физических
секций. Соседние снимки нужны для интервальных вычислений. Явные границы
отчёта заданы в `github-pages-hour-20260921T085946Z.slice`.

`scripts/build-pages-report.sh` проверяет контрольную сумму, дважды создаёт
HTML из фиксированной записи, сравнивает файлы побайтово и проверяет отчёт
офлайн в Chromium.

Исходные `github-pages-hour.zms`, контрольная сумма и границы сохраняют
запись за 5 сентября 2026 года, используемую в примерах руководства оператора.
