# kronika-report

[English version](README.md) · [Установка](../../INSTALL.ru.md)

`kronika-report` превращает файл записи `.zms` в интерактивный HTML-отчёт,
который открывается прямо в браузере. Используйте готовый сегмент сборщика
или интервал, вырезанный командой `kronika-dump slice`.
Исходники: [команда и проверка аргументов](src/main.rs),
[справка параметров](src/help.rs).

```sh
kronika-report incident.zms incident.html
```

## Параметры

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| `INPUT.zms` | Обязателен | Корректный готовый файл записи ZMS; имя до расширения может быть любым. |
| `OUTPUT.html` | Обязателен | Путь `.html`. Существующий файл заменяется одной операцией после подготовки нового. Родительский каталог должен существовать и быть доступен на запись. |
| `--from MICROSECONDS` | Первая записанная микросекунда | Начало доступного в отчёте интервала, включительно. |
| `--to-exclusive MICROSECONDS` | Последняя записанная микросекунда + 1 | Конец доступного интервала, не включённый в него. |
| `-h`, `--help` | — | Справка параметров; программа завершается до обращения к файлам. |
| `--version` | — | Версия программы; она завершается до обращения к файлам. |

Явные границы задаются вместе в указанном порядке перед обоими путями и должны
удовлетворять `0 < from < to-exclusive <= 9007199254740991`.
Это целые числа микросекунд с начала эпохи Unix. Интервал
`[from, to-exclusive)` включает начало и не включает конец.

<a id="exact-report-interval"></a>
## Точный интервал отчёта

```sh
kronika-report --from 1788634800000000 --to-exclusive 1788638400000000 \
  incident.zms incident.html
```

Пример выбирает 5 сентября 2026, 19:00–20:00 UTC.
[Срез ZMS](../kronika-dump/README.ru.md#slice) может содержать соседние отсчёты
для интервальных вычислений. Явные границы ограничивают перемещение по отчёту,
но соседние отсчёты остаются доступны для расчётов. Если для первого значения
скорости нужен более ранний отсчёт, которого нет, результат остаётся `null`.

## Результат и выполнение

Команда проверяет ZMS и строит индекс для поиска по записи. Данные, индекс,
интерфейс и программа обработки запросов на Rust/WebAssembly включаются в HTML.
Она выполняется в основном потоке браузера. Таблицы,
тепловые карты, поиск и графики работают локально. В отчёте нет аутентификации,
MCP, автоматического обновления данных и кнопки Export.

Временный HTML создаётся рядом с `OUTPUT.html`; отдельный файл IDX не создаётся.
Программа не читает настройки из переменных окружения. При успехе код
завершения равен 0, стандартный вывод (stdout) пуст. Ошибки выводятся в поток
ошибок (stderr) с ненулевым кодом завершения. `Ctrl+C` прерывает преобразование.
Кнопка **Export** в веб-интерфейсе создаёт такой же HTML и ограничивает его выбранным
интервалом.
