# История изменений

[English version](changelog.md)

## 1.1.0 — Невыпущено

Изменения после последнего опубликованного релиза 1.0.1.

- Подключение к одному серверу PostgreSQL через `KRONIKA_PG_DSN`. Для нескольких серверов запускайте один и тот же бинарник `kronika-collector` отдельным процессом на каждый сервер, со своими `KRONIKA_PG_DSN` и `KRONIKA_STORAGE_DIR`. Каждый процесс собирает доступные базы своего сервера.
- Плановое закрытие ZMS-сегментов разнесено во времени: для каждого каталога хранения сохраняется сдвиг расписания, действующий и после перезапуска. Первый сегмент может быть короче; последующие плановые сегменты сохраняют заданный период. Ограничения размера, принудительное закрытие и восстановление не меняются. Одновременные закрытия всё ещё возможны.

`KRONIKA_PG_DSNS` устарел: используется только первый DSN; параметр будет удалён. Используйте `KRONIKA_PG_DSN`.

### Другие изменения

- Добавлен `KRONIKA_COLLECTOR_MODE=postgresql` для локального или удалённого PostgreSQL без сбора метрик Linux и без sudo. Прежний режим `local` сохраняет сбор OS той же VM или pod с необязательным PostgreSQL. См. [настройки коллектора](bins/kronika-collector/README.ru.md).
- Добавлен сбор всех видимых и доступных групп cgroup v2. Их CPU, Memory, I/O и Tasks показаны в таблицах с поиском, сортировкой и историей. Данные групп разделены; отсутствие лимита отличается от недоступного значения. Старые записи по-прежнему читаются.
- Записи PostgreSQL 12 и старых версий `pg_stat_statements` читаются без запросов отсутствующих полей. Для старых вариантов записи используется `total_time`; недоступные в записи показатели Activity скрыты.
- В HTML-отчётах за неполный час Activity занимает только записанный интервал. Клик по ячейке и переход к строке выбирают соответствующее время, а не начало отчёта.

## [1.0.1](https://github.com/pgtoolz/Kronika/releases/tag/v1.0.1) — 2026-09-06

- Уточнены инструкции установки и запуска на русском и английском: подключение к локальному PostgreSQL и источник измерений Linux при подключении к удалённому серверу.

## [1.0.0](https://github.com/pgtoolz/Kronika/releases/tag/v1.0.0) — 2026-09-06

- Первый релиз: запись Linux и PostgreSQL, просмотр через web и самостоятельные HTML-отчёты без сети. Статические архивы Linux для x86-64 и ARM64 включают коллектор, web-сервер, инструменты dump и report.
