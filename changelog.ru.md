# История изменений

[English version](changelog.md)

## 1.1.0 — Невыпущено

Изменения после последнего опубликованного релиза 1.0.1.

- Добавлен `KRONIKA_PG_DSN` — строка подключения к PostgreSQL. Для сбора с нескольких серверов запускайте `kronika-collector` для каждого сервера, указав его `KRONIKA_PG_DSN` и отдельный каталог `KRONIKA_STORAGE_DIR`.
- Сборщики закрывают ZMS по расписанию со случайным сдвигом по времени. Этот сдвиг сохраняется после перезапуска; одновременные закрытия возможны.

`KRONIKA_PG_DSNS` устарел и будет удалён: используется только первый DSN. Замените его на `KRONIKA_PG_DSN`, удалив старую переменную. Если заданы обе, сборщик не запустится.

### Другие изменения

- Добавлен `KRONIKA_COLLECTOR_MODE=postgresql` для сбора данных локального или удалённого PostgreSQL без метрик Linux. В режиме `local` доступны метрики Linux той же VM или pod и, при необходимости, PostgreSQL. См. [настройки сборщика](bins/kronika-collector/README.ru.md).
- Добавлен сбор всех видимых и доступных групп cgroup v2. Их CPU, Memory, I/O и Tasks показаны в таблицах с поиском, сортировкой и историей. Данные групп разделены; отсутствие лимита отличается от недоступного значения. Старые записи по-прежнему читаются.
- Исправлено чтение записей PostgreSQL 12 и старых версий `pg_stat_statements`: отсутствующие поля не запрашиваются. Показатели Activity, которых нет в записи, скрыты.
- В HTML-отчётах за неполный час Activity занимает только записанный интервал. Клик по ячейке и переход к строке выбирают соответствующее время, а не начало отчёта.

## [1.0.1](https://github.com/pgtoolz/Kronika/releases/tag/v1.0.1) — 2026-09-06

- Уточнены инструкции установки и запуска на русском и английском: подключение к локальному PostgreSQL и источник измерений Linux при подключении к удалённому серверу.

## [1.0.0](https://github.com/pgtoolz/Kronika/releases/tag/v1.0.0) — 2026-09-06

- Первый релиз: запись Linux и PostgreSQL, просмотр в браузере и автономные HTML-отчёты. Статические архивы Linux для x86-64 и ARM64 включают сборщик, веб-сервер и инструменты dump и report.
